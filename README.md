# Game Scratch của Mana

Hai game Scratch dùng mô hình học máy qua camera, chạy trên Scratch của Machine Learning for Kids.

## Mana Oẳn tù xì

Mana nhìn bàn tay qua camera bằng mô hình học máy, đấu Oẳn tù xì với máy.

Mở game: https://machinelearningforkids.co.uk/scratch/?project=https://raw.githubusercontent.com/kkhmn4/mana-oan-tu-xi/main/mana-oan-tu-xi.sb3

## Quầy trái cây của Mana

Mana đứng quầy tính tiền, nhận ra quả cam, táo, chuối qua camera, bỏ vào đúng giỏ và cộng tiền vào hóa đơn. Mana chưa chắc thì hỏi người. Có nút SỬA và chế độ giờ cao điểm 60 giây.

Mở game: https://machinelearningforkids.co.uk/scratch/?project=https://raw.githubusercontent.com/kkhmn4/mana-oan-tu-xi/main/quay-trai-cay-mana.sb3
